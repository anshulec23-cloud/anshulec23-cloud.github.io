Sentinel

Real-time video anomaly detection that learns what ordinary movement looks like and flags what it cannot reproduce — running the whole path from frame to alert on one machine, with no labelled anomaly dataset to collect.

Domain
Computer vision
Detects
Running, loitering, fighting, unknown
Stack
PyTorch, YOLOv8, DeepSORT, FastAPI
Licence
Apache-2.0

The problem

Supervised anomaly detection in video has a dataset problem that no amount of model architecture fixes: anomalies are, by definition, the thing you have the fewest examples of. Collecting a labelled corpus of fights and break-ins for every new camera angle is not a plan.

So Sentinel inverts it. Train only on normal movement, and treat reconstruction failure as the signal. The model never needs to see an anomaly to flag one.

How it works

video (file / webcam / RTSP)
      |
      v
[ detection ]   YOLOv8n -> person bounding boxes, 25+ FPS
      |
      v
[ tracking  ]   DeepSORT -> stable track IDs across frames
      |
      v
[ anomaly   ]   9-dim motion feature buffer, per track
      |         LSTM autoencoder reconstructs the sequence
      |         high reconstruction error + rule fusion
      v
[ logging   ]   events.jsonl + in-memory ring buffer
      |
      v
[ api       ]   FastAPI: MJPEG stream, /ws/alerts, /api/events

Identity is what makes motion meaningful

A bounding box on its own says nothing about behaviour. DeepSORT holds a person's identity across frames, which turns a sequence of boxes into a trajectory — and trajectories are where loitering, sprinting and scuffles actually live. Lose the track ID and the anomaly disappears with it.

Nine numbers per person per frame

Each track carries a compact feature vector — normalised centroid, normalised box dimensions, velocity in x and y, scalar speed, acceleration, and clamped aspect ratio. Everything is normalised against frame dimensions and the frame diagonal, so the model is not relearning the scene every time the camera changes resolution or position.

Aspect ratio is the quiet one: a standing person and a person on the ground differ sharply in it, which is what makes a fall or a tackle separable from fast walking.

Model plus rules, not model alone

The detector fuses autoencoder reconstruction error with explicit rules. The model catches the unknown category — movement that is simply unlike anything in training — while the rules keep the named classes stable and interpretable. An operator who asks "why did it alert?" gets an answer either way.

Honest limits

Unsupervised detection trades a labelling problem for a threshold problem. Reconstruction error has no natural cut-off: set it tight and a crowded platform generates noise, set it loose and genuine events slip past. The rule layer exists partly to cover that, and partly because an operator will not trust a number they cannot interrogate.

Dependency

Accuracy inherits YOLOv8's weaknesses. Heavy occlusion, unusual camera angles and crowds degrade detection, and anything the detector misses the tracker never sees — errors compound down the pipeline rather than cancelling out.
